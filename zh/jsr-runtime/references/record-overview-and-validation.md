# 总览与验证记录

## 一、用途

`总览.md` 记录当前 runtime 会话的阶段快照。`验证记录.md` 记录补项、状态闭合或分叉判断的证明过程。

最小运行时清单本体继续写在 `运行时依赖.md`，不要挪到 `总览.md`。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├─ 会话1/
│  ├─ 总览.md
│  ├─ 请求链路.md
│  ├─ 运行时依赖.md
│  ├─ 恢复记录.md
│  └─ 验证记录.md
├─ 会话2/
│  └─ ...
└─ ...
```

## 五、路由规则

- `总览.md` 负责 `当前阶段 / 已确认 / 当前卡点 / 下一步 / 风险 / 待验证` 和当前 blocked / partial 状态块。
- `运行时依赖.md` 负责最小清单、纯算迁移前检查、可移除项和当前链路需要的 runtime 事实。
- `验证记录.md` 在补项开关、状态闭合或分叉点需要证明时开始记录。

## 六、检查标准

- `总览.md` 含有六个固定阶段字段。
- `运行时依赖.md` 继续只写 runtime 事实。
- `验证记录.md` 要明确固定输入和补项开关。
- 详细验证内容不能只写在 `运行时依赖.md`。

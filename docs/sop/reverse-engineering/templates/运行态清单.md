# 运行态清单

用途：记录当前链路的最小运行时清单、执行路线、纯算迁移前检查和验证联动要求。

填写规则：
- 只记录已证明影响结果的依赖。
- 不写浏览器环境常识。
- 每个依赖项都必须回答 `必要性 / 证据 / 去掉后现象`。

- `样本编号`：

- `适配检查`：按 `结论 / 观测信号 / 证据编号` 填写；不涉及则填 `不适用`。
- `执行模式`：按 `本地回放 / 远程被动 / 远程主动 / 不适用` 之一填写，并附 `选择原因 / 证据编号`。
- `浏览器画像`：填写当前链路锁定的画像；无则填 `无`。
- `注入时机`：填写接管位置与证据编号；不涉及则填 `不适用`。
- `状态闭合信号`：填写 `信号 / 状态载体 / 证据编号`；不涉及则填 `不适用`。
- `状态载体`：填写运行时状态最终落到哪里；不涉及则填 `不适用`。

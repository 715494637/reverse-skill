# 总览与验证记录

## 一、用途

`总览.md` 记录当前定位会话的阶段快照。

本 reference 就是定位阶段 `总览.md` 和 `验证记录.md` 的唯一权威骨架。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├─ 会话1/
│  ├─ 总览.md
│  ├─ 请求链路.md
│  ├─ 运行态清单.md
│  ├─ 恢复记录.md
│  └─ 验证记录.md
├─ 会话2/
│  └─ ...
└─ ...
```

## 五、归属规则

- `总览.md` 负责 `当前阶段 / 已确认 / 当前卡点 / 下一步 / 风险 / 待验证` 和当前规范化状态块。
- 正常态 / 风控态对比表和分叉图只能放在 `总览.md`，不能写进 `请求链路.md`。
- `请求链路.md` 负责请求区块、状态数组、`来源/去向`、证据和上游展开，以及按需连接信息。
- `验证记录.md` 在 sink 假设、状态闭合或分叉假设需要证明时开始记录。
- `验证记录.md` 可以由 `定位` 提前启动，但归属阶段和完成门禁仍然属于 `验证`。
- 验证目标只能是 sink 证明、状态链闭合或分叉证明。

## 六、检查标准

- `总览.md` 含有六个固定阶段字段。
- 只要阶段处于 `部分完成 / 阻塞`，`总览.md` 就必须填完整的当前状态块。
- 只有在存在风控分支时才写分叉图。
- `验证记录.md` 使用具体检查点，而不是只有最终结论。
- 请求结构内容不混进 `总览.md`。

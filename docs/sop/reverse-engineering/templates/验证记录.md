# 验证记录

用途：记录浏览器基线、本地对照、允许误差、验证结论。

填写规则：
- 不写“已验证”这类空结论。
- 每次验证必须绑定基线样本。

## 填写模板

- `基线样本编号`：
- `对照样本编号`：
- `证据编号`：
- `验证对象`：填写字段、请求、响应、状态转移或工程化产物。
- `输入对照`：填写浏览器侧输入与本地侧输入。
- `输出对照`：填写浏览器侧输出与本地侧输出。
- `允许误差`：按 `比较项 / 运算符 / 阈值 / 单位` 填写；不允许误差时填 `差异数 / = / 0 / 项`。
- `失败样本`：无失败样本时填 `无`。
- `差异定位`：填写差异出现的位置、阶段、证据编号。
- `验证结论`：只填 `通过`、`失败`、`部分通过` 之一；填 `部分通过` 时，`失败样本` 与 `差异定位` 不得为 `无`。

# 请求链路

用途：只记录请求结构、字段状态、来源链、去向链、上游展开和按需连接信息。

填写规则：
- 每个结论必须绑定样本编号和证据编号。
- 目标请求必须排在最前面。
- 一次请求写一个区块。
- 每个请求输入字段都必须写 `状态 / 来源 / 证据`。
- 每个响应输出字段都必须写 `状态 / 去向 / 证据`。
- `状态` 必须是数组，不写散文。
- 不写当前阶段、当前卡点、下一步、分叉图、运行时补丁、恢复总结。

## 填写模板

- `样本编号`：
- `证据编号`：
- `目标请求`：
- `目标对象`：填写本次追踪的字段、请求头、`cookie`、消息对象或请求体。
- `当前样本状态`：按 `正常态 / 风控态 / 未知` 填写。
- `未闭环项`：无则填 `无`。

```markdown
## 请求A
- 接口：
- 触发方式：
- 响应结果：
- 上游请求：`请求B`、`请求C`

### 请求头
- `头1`
  - 状态：`["动态","响应获取","会话相关"]`
  - 来源：`请求B.response.token -> 请求A.header.头1`
  - 证据：`发送前对照`

### Query 参数
- `参数1`
  - 状态：`["固定","明文"]`
  - 来源：`页面固定值 -> 请求A.query.参数1`
  - 证据：`抓包`

### Body 参数
- `参数2`
  - 状态：`["动态","响应获取","一次性"]`
  - 来源：`请求C.response.ticket -> 请求A.body.参数2`
  - 证据：`响应包`

### Cookie
- `cookie1`
  - 状态：`["动态","响应获取","HttpOnly","会话相关"]`
  - 来源：`请求B.Set-Cookie.cookie1 -> 请求A.cookie.cookie1`
  - 证据：`Set-Cookie`

### 响应输出
- `response.field1`
  - 状态：`["动态","响应获取","可复用"]`
  - 去向：`请求D.header.头2`
  - 证据：`响应包`
```

# 总览与验证记录

## 一、用途

`总览.md` 记录当前运行时会话的阶段快照。

本 reference 就是运行时阶段 `总览.md` 和 `验证记录.md` 的唯一权威骨架。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├── 会话1/
│   ├── 总览.md
│   ├── 请求链路.md
│   ├── 运行态清单.md
│   ├── 恢复记录.md
│   └── 验证记录.md
├── 会话2/
│   └── ...
└── ...
```

## 五、归属规则

- `总览.md` 负责 `当前阶段 / 已确认 / 当前卡点 / 下一步 / 风险 / 待验证` 和当前状态块。
- `运行态清单.md` 负责最小清单、纯算迁移前检查、可移除项，以及当前链路真正需要的运行时事实。
- `验证记录.md` 只要需要证明补项开关、状态闭合、路线选择或分叉点，就要开始记录。
- `验证记录.md` 可以由 `运行时` 提前启动，但归属阶段和完成门禁仍然属于 `验证`。
- 只要依赖生命周期或导航产状态，就必须填写 `路线证明`。

## 六、检查标准

- `总览.md` 含有六个固定阶段字段。
- 只要阶段处于 `部分完成 / 阻塞`，`总览.md` 就必须填完整的当前状态块。
- `运行态清单.md` 继续只写运行时事实。
- `验证记录.md` 要明确固定输入和补项开关。
- 命中 `sdenv` 形态时，`验证记录.md` 还要明确路线证明。
- 详细验证内容不能只写在 `运行态清单.md`。

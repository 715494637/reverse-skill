# 请求链路记录

## 一、用途

`请求链路.md` 只记录请求结构、字段状态数组、来源证明、去向证明、上游展开和按需连接信息。

本 reference 就是 `请求链路.md` 的唯一权威骨架。

不要在这里写：

- 当前阶段、当前卡点、下一步、总结结论
- 正常态 / 风控态分叉图
- 运行时补丁决策
- 恢复结论或等价性判断

这些内容分别属于其他记录文件。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├─ 会话1/
│  ├─ 总览.md
│  ├─ 请求链路.md
│  ├─ 运行态清单.md
│  ├─ 恢复记录.md
│  └─ 验证记录.md
├─ 会话2/
│  └─ ...
└─ ...
```

会话规则：

- 一个逆向会话只用一个 `会话N/` 目录
- 用户指定 `会话N` 时，只读写那个目录
- 用户未指定时，创建下一个未占用的 `会话N/` 目录
- 不得覆盖或编辑其他 `会话N/` 目录

## 三、状态标签标准

`状态` 必须使用数组，并保留下列标签：

- `未知`
- `已知`
- `固定`
- `动态`
- `明文`
- `加密`
- `本地计算`
- `响应获取`
- `环境产生`
- `会话相关`
- `风控相关`
- `时序相关`
- `一次性`
- `可复用`
- `HttpOnly`

示例：

```json
["动态", "响应获取", "HttpOnly", "会话相关"]
```

## 四、文件头

`请求链路.md` 顶部先写下面这些字段：

```markdown
# 请求链路

- 样本编号：
- 证据编号：
- 目标请求：
- 目标对象：
- 当前样本状态：正常态 / 风控态 / 未知
- 未闭环项：
```
## 五、填写规则

- 目标请求必须排第一。
- 上游请求跟在目标请求之后逐层展开。
- 一个请求区块只写一个请求。
- 每个请求区块只能使用：`请求头`、`Query 参数`、`Body 参数`、`Cookie`、`响应输出`。
- 每个请求输入字段都必须包含 `状态 / 来源 / 证据`。
- 每个响应输出字段都必须包含 `状态 / 去向 / 证据`。
- `状态` 只能写数组，不能写散文。
- `来源` 一律写成 `来源字段 -> 目标字段`。
- `去向` 一律写成 `当前响应字段 -> 下游目标字段`。
- 某个请求没有上游请求时，明确写 `上游请求：无`。
- 某个区块没有字段时，明确写 `- 无`。

不要另起下面这些区块：

- 依赖总结
- 当前结论
- 正常态 / 风控态对比

依赖已经由字段级 `来源/去向` 和请求级 `上游请求` 表达。

## 六、请求区块示例

```markdown
## 请求A
- 接口：
- 触发方式：
- 响应结果：
- 上游请求：`请求B`、`请求C`

### 请求头
- `头1`
  - 状态：`["动态","响应获取","会话相关"]`
  - 来源：`请求B.response.token -> 请求A.header.头1`
  - 证据：`发送前对照`

### Query 参数
- `参数1`
  - 状态：`["固定","明文"]`
  - 来源：`页面固定值 -> 请求A.query.参数1`
  - 证据：`抓包`

### Body 参数
- `参数2`
  - 状态：`["动态","响应获取","一次性"]`
  - 来源：`请求C.response.ticket -> 请求A.body.参数2`
  - 证据：`响应包`

### Cookie
- `cookie1`
  - 状态：`["动态","响应获取","HttpOnly","会话相关"]`
  - 来源：`请求B.Set-Cookie.cookie1 -> 请求A.cookie.cookie1`
  - 证据：`Set-Cookie`

### 响应输出
- `response.field1`
  - 状态：`["动态","响应获取","可复用"]`
  - 去向：`请求D.header.头2`
  - 证据：`响应包`
```

## 七、协议与长连接补充

遇到 `WebSocket`、`protobuf`、SSE、心跳、续期流时，普通请求区块照写，并在末尾补一个连接信息区块：

```markdown
## 连接信息
- 连接：
- 当前状态：
- 会话标识：
- 序号规则：
- ack 规则：
- 续期条件：
```

## 八、检查标准

- 目标请求排在最前面。
- 每个字段都有状态数组。
- 每个字段都有具体来源链或下游目标。
- 每个字段至少有一个证据锚点。
- 不需要额外总结区块，也能读清上游展开。
- 进度、分叉、运行时、恢复类内容没有混进这个文件。

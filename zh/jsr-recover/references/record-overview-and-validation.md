# 总览与验证记录

## 一、用途

`总览.md` 记录当前 recover 会话的阶段快照。`验证记录.md` 记录当前恢复级别和提炼结果是否可信。

结构卡片继续写在 `恢复记录.md`，不要把桥接、层级或关键函数细节挪进 `总览.md`。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├─ 会话1/
│  ├─ 总览.md
│  ├─ 请求链路.md
│  ├─ 运行时依赖.md
│  ├─ 恢复记录.md
│  └─ 验证记录.md
├─ 会话2/
│  └─ ...
└─ ...
```

## 五、路由规则

- `总览.md` 负责 `当前阶段 / 已确认 / 当前卡点 / 下一步 / 风险 / 待验证` 和当前 blocked / partial 状态块。
- `恢复记录.md` 负责层级卡片、桥接卡片、状态载体和关键函数卡片。
- `验证记录.md` 在等价性工作或固定输入检查开始时记录。

## 六、检查标准

- `总览.md` 含有六个固定阶段字段。
- 只要阶段处于 `partial / blocked`，`总览.md` 就必须填完整的当前状态块。
- `恢复记录.md` 继续只写结构。
- `验证记录.md` 使用具体检查点，并明确剩余缺口。

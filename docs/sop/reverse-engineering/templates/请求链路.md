# 请求链路

用途：统一逆向证据工件。记录请求结构、字段状态、来源链、去向链、上游展开，以及恢复、运行时、验证、交接补充。

填写规则：
- 每个结论必须绑定样本编号和证据编号。
- 目标请求必须排在最前面。
- 一次请求写一个区块，区块之间用 `---` 分隔。
- 每个请求输入字段都必须写 `状态 / 来源 / 证据`。
- 每个响应输出字段都必须写 `状态 / 去向 / 证据`。
- `状态` 必须是数组，不写散文。
- 各补充区（恢复、运行时、验证）按需添加，不提前占位。

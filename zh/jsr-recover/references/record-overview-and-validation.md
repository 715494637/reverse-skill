# 总览与验证记录

## 一、用途

`总览.md` 记录当前恢复会话的阶段快照。

本 reference 就是恢复阶段 `总览.md` 和 `验证记录.md` 的唯一权威骨架。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├─ 会话1/
│  ├─ 总览.md
│  ├─ 请求链路.md
│  ├─ 运行态清单.md
│  ├─ 恢复记录.md
│  └─ 验证记录.md
├─ 会话2/
│  └─ ...
└─ ...
```

## 五、归属规则

- `总览.md` 负责 `当前阶段 / 已确认 / 当前卡点 / 下一步 / 风险 / 待验证` 和当前状态块。
- `恢复记录.md` 负责层级卡片、桥接卡片、状态载体、恢复级别、停止理由和关键函数卡片。
- `验证记录.md` 在等价性工作或固定输入检查开始时记录。
- `验证记录.md` 可以由 `恢复` 提前启动，但归属阶段和完成门禁仍然属于 `验证`。
- 验证目标只能是恢复级别、桥接契约和等价性检查点。

## 六、检查标准

- `总览.md` 含有六个固定阶段字段。
- 只要阶段处于 `部分完成 / 阻塞`，`总览.md` 就必须填完整的当前状态块。
- `恢复记录.md` 必须说明为什么可以停在当前恢复级别。
- `验证记录.md` 使用具体检查点，并明确剩余缺口。

# 逆向工程 SOP

用途：作为唯一标准流程入口。只定义阶段门禁、状态、交付前提。

填写规则：
- 本文档只维护流程，不记录案例。
- 结论以模板产物为准，不在此重复展开。

## 标准流程

`任务归一化 -> 证据采集 -> Locate -> Runtime -> Recover -> Validation -> Delivery`

## 阶段门禁

| 阶段 | 进入条件 | 必交付 | 退出条件 | 失败输出 |
| --- | --- | --- | --- | --- |
| 任务归一化 | 已有目标站点、目标对象、至少一个可观察样本 | `任务卡.md` | 目标对象、触发入口、成功标准、约束已锁定 | `blocked` |
| 证据采集 | 已完成任务归一化 | 样本包 | 至少获得一个可信正常态样本 | `partial` / `blocked` |
| Locate | 已知目标请求、字段、header、cookie、消息对象之一 | `请求链路.md` | 已确认真实写边界、触发动作、上游依赖、状态来源、分支位置 | `partial` |
| Runtime | 浏览器与本地执行不一致，或已发现环境依赖 | `运行态清单.md` | 已确认最小运行时清单与必要补丁边界 | `partial` |
| Recover | 真实语义被混淆层、封装层、运行时层遮蔽 | `恢复记录.md` | 已恢复到可解释语义层，可继续验证 | `partial` |
| Validation | 已有定位结论、运行时结论或恢复结论 | `验证记录.md` | 已完成浏览器基线对照并给出验证结论 | `failed` |
| Delivery | Validation 通过 | `交付清单.md` | 已明确允许交付物、禁止交付物、残余风险 | `no-go` |

## 状态定义

| 状态 | 使用条件 | 强制内容 |
| --- | --- | --- |
| `blocked` | 缺目标、缺样本、缺访问路径，当前阶段无法开始 | 阻塞项、所缺证据、解除条件 |
| `partial` | 已完成局部确认，但证据未闭环，禁止向后冒进 | 已证实内容、未证实内容、下一动作 |
| `failed` | 已进入验证，但对照结果不成立 | 失败样本、差异点、回退阶段 |
| `no-go` | Validation 未通过或残余风险超出交付边界 | 禁止交付物、未满足前提 |

## 交付前提

- 未填写 `验证记录.md` 不得进入 Delivery。
- `验证记录.md` 无明确结论，不得允许任何工程化产物。
- `交付清单.md` 只能引用已验证结论，不得补写新推断。

## 样本包最小内容

- `样本编号`
- `证据编号`
- `目标对象`
- `触发步骤`
- `请求快照或消息快照`
- `响应快照、响应编号或响应包编号`
- `cookie / 状态快照`
- `时间点或时间窗口`
- `正常态标记`

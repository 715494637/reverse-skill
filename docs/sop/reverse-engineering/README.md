# 逆向工程 SOP

用途：作为唯一标准流程入口。只定义阶段门禁、统一状态契约、交付前提，以及中央模板的权威边界。

填写规则：
- 本文档只维护流程和契约，不记录案例。
- 所有执行产物以 `templates/` 下的中央模板为准。
- 阶段 reference 只能补充归属、触发时机和质量检查，不能再定义第二套骨架。

## 标准流程

`任务归一化 -> 证据采集 -> 定位 -> 运行时 -> 恢复 -> 验证 -> 交付`

## 阶段门禁

| 阶段 | 进入条件 | 必交付 | 退出条件 | 失败输出 | 继续规则 |
| --- | --- | --- | --- | --- | --- |
| 任务归一化 | 已有目标站点、目标对象、至少一个可观察样本 | `任务卡.md` | 目标对象、触发入口、成功标准、约束已锁定 | `阻塞` | 只有 `任务卡.md` 锁定主样本和下一动作后，才进入 `证据采集` |
| 证据采集 | 已完成任务归一化 | 样本包 | 至少获得一个可信正常态样本 | `部分完成 / 阻塞` | 只有样本可信后，才进入 `定位 / 运行时 / 恢复` 之一 |
| 定位 | 已知目标请求、字段、请求头、`cookie`、消息对象之一 | `请求链路.md` | 已确认真实写边界、触发动作、上游依赖、状态来源，并对正常态 / 风控态分叉给出闭合结论或明确排除 | `部分完成` | 只有写边界、来源类别、上游闭合和分叉结论都满足当前目标所需粒度后，才允许升级到下游阶段 |
| 运行时 | 浏览器与本地执行不一致，或已发现环境依赖 | `运行态清单.md` | 已确认最小运行时清单、必要补丁边界、纯算迁移前检查结论和验证联动要求 | `部分完成` | 只有最小补项、影响证据、可移除项和复验结果齐全后，才允许继续；命中 `sdenv` 路线时，还必须闭合适配检查、执行模式、状态闭合信号，并启动 `验证记录.md` 记录路线证明 |
| 恢复 | 真实语义被混淆层、封装层、运行时层遮蔽 | `恢复记录.md` | 已恢复到可解释语义层，并明确恢复级别与停止理由，可继续验证 | `部分完成` | 只有恢复级别、桥接边界、状态载体或关键算子已闭合到当前目标所需粒度后，才允许继续 |
| 验证 | 已有定位结论、运行时结论或恢复结论 | `验证记录.md` | 已完成浏览器基线对照并给出验证结论 | `失败` | 只有验证结论为 `通过 / 部分通过` 且差异已定位时，才允许进入 `交付`；命中 `sdenv` 路线时，还必须完成二跳验证。`验证记录.md` 可由 `定位 / 运行时 / 恢复` 提前启动，但归属和完成仍在 `验证` |
| 交付 | 验证通过 | `交付清单.md` | 已明确允许交付物、禁止交付物、残余风险 | `不可交付` | 只允许引用上游已验证状态块，不得补写新推断 |

## 状态定义

| 状态 | 使用条件 | 强制内容 |
| --- | --- | --- |
| `就绪` | 已具备当前阶段起始输入，且当前没有已确认的阻塞、失败或交付禁行结论 | 当前阶段目标、当前样本或工件、下一动作 |
| `部分完成` | 已完成局部确认，但证据未闭环，禁止向后冒进 | 已证实内容、未证实内容、下一动作 |
| `阻塞` | 缺目标、缺样本、缺访问路径，当前阶段无法开始 | 阻塞项、所缺证据、解除条件 |
| `失败` | 已进入验证，但对照结果不成立 | 失败样本、差异点、回退阶段 |
| `不可交付` | 验证未通过或残余风险超出交付边界 | 禁止交付物、未满足前提 |

## 统一状态块

当前状态块默认由 `总览.md` 持有最新版本；其他阶段产物只引用，不重复定义第二套字段：

```markdown
- 状态：`就绪 / 部分完成 / 阻塞 / 失败 / 不可交付`
- 阶段：
- 代码：
- 摘要：
- 证据：
- 影响：
- 下一动作：
```

`产物 / 样本编号 / 证据编号 / 继续规则` 属于各阶段正文，不属于统一状态块本体。

## 统一失败对象

凡是 `部分完成 / 阻塞 / 失败 / 不可交付`，都要能展开成下面这个平铺失败对象：

```markdown
- 阶段：
- 代码：
- 摘要：
- 证据：
- 影响：
- 下一动作：
```

## 交付前提

- 未填写 `验证记录.md` 不得进入 `交付`。
- `验证记录.md` 无明确结论，不得允许任何工程化产物。
- `交付清单.md` 必须引用上游最新状态块和失败对象，不能自行重写阶段结论。
- `交付清单.md` 只能引用已验证结论，不得补写新推断。
- 只要交付项属于 `sdenv` 或运行时驱动产物，必须同时引用运行时阶段的适配检查、执行模式、状态闭合信号和二跳验证。

## 样本包最小内容

- `样本编号`
- `证据编号`
- `目标对象`
- `触发步骤`
- `请求快照或消息快照`
- `响应快照、响应编号或响应包编号`
- `cookie / 状态快照`
- `时间点或时间窗口`
- `正常态标记`

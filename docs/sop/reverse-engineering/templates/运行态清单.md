# 运行态清单

用途：记录最小运行时依赖和必要补丁边界。

填写规则：
- 只记录已证明影响结果的依赖。
- 不写浏览器环境常识。

## 填写模板

- `样本编号`：
- `证据编号`：
- `失败现象`：填写浏览器与本地的具体差异。
- `缺失对象`：只填写已证明必须存在的对象、属性或接口；无则填 `无`。
- `缺失状态`：只填写已证明必须存在的会话态、页面态、存储态；无则填 `无`。
- `反调试点`：填写调试器检测、时间探针、控制台探针、环境探针等触发点；无则填 `无`。
- `时间源`：填写参与结果形成的时间接口、时间值或时间窗口；无则填 `无`。
- `随机源`：填写参与结果形成的随机接口、种子或随机输入；无则填 `无`。
- `指纹面`：填写被消费的指纹面与消费位置；无则填 `无`。
- `最小补丁`：按 `补丁面 / 变更点 / 预期影响 / 证据编号` 填写，不得省略变更点。
- `补丁验证`：填写补丁前后差异及证据编号。
- `运行态结论`：只填 `已确认`、`部分确认`、`未确认` 之一，并附证据编号。

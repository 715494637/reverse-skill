# 等价性验证与恢复记录

## 一、用途

`恢复记录.md` 和 `验证记录.md` 只记录恢复结构与验证证明。

以下内容不要写在这里：

- 完整请求链展开
- 最小运行时清单
- 通用进度总结

这里只回答恢复了什么、缺口还在哪、为什么这份结果可信。

## 二、落盘路径

默认写到当前任务工作目录：

```text
reverse-records/
├─ 会话1/
│  ├─ 总览.md
│  ├─ 请求链路.md
│  ├─ 运行时依赖.md
│  ├─ 恢复记录.md
│  └─ 验证记录.md
├─ 会话2/
│  └─ ...
└─ ...
```

会话规则：

- 一个逆向会话只使用一个 `会话N/` 目录。
- 用户指定了 `会话N`，就只用那个目录。
- 用户未指定时，创建下一个未占用的 `会话N/` 目录。
- 不得覆盖或改写其他 `会话N/` 目录。

## 三、写法规则

- `恢复记录.md` 记录层级、边界、状态载体、关键函数卡片。
- `验证记录.md` 记录检查点、固定输入、等价结果、缺口位置。
- 检查点必须具体，不只比较最终输出。
- 层级名称必须明确：`外层容器`、`调度层`、`状态载体`、`桥接层`、`核心算子`、`写回层`。
- 每张关键函数卡片都必须写 `输入`、`输出`、`副作用`、`依赖`、`证据`。

## 六、检查标准

- 恢复结构与验证证明已经分开。
- 层级名称明确。
- 关键函数卡片具体。
- 检查点具体。
- 缺口位置明确。
- 非 recover 内容没有混入这些文件。

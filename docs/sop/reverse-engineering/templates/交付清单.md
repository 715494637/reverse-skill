# 交付清单

用途：记录允许交付物、禁止交付物、前置依赖、残余风险。

填写规则：
- 未填写 `样本编号`、`证据编号`、`验证记录引用` 时，`交付结论` 只能填 `不可交付`。
- `验证记录引用` 未显示 `通过` 或 `部分通过` 时，`交付结论` 只能填 `不可交付`。
- 交付项属于 `sdenv` 或其他运行时驱动产物时，必须补 `运行时路线前置`。
- 不写实现设想。

## 填写模板

- `样本编号`：
- `证据编号`：
- `验证记录引用`：
- `上游状态块引用`：按 `文件 / 状态 / 阶段 / 代码 / 证据编号` 填写。
- `上游失败对象引用`：按 `阶段 / 代码 / 证据 / 下一动作` 填写；无则填 `无`。
- `运行时路线前置`：按 `适配检查 / 执行模式 / 状态闭合 / 二跳验证` 填写；不涉及运行时产物则填 `不适用`。
- `交付项表`：一行一项，按 `交付项 / 验证记录编号 / 验证范围 / 前置依赖 / 残余风险 / 结论` 填写。
- `禁止交付项`：填写当前不得交付的项。
- `禁止动作`：填写交付后仍不得执行的动作。
- `交付结论`：按 `结论 / 样本编号 / 证据编号` 填写，结论只填 `允许交付` 或 `不可交付`。

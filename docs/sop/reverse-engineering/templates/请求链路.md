# 请求链路

用途：记录写边界、上游依赖、状态来源、分支位置。

填写规则：
- 每个结论必须绑定样本编号和证据编号。
- 只保留已确认边界，不写与本案无关的步骤。

## 填写模板

- `样本编号`：
- `证据编号`：
- `目标对象`：填写本次追踪的字段、header、cookie、消息对象或请求体。
- `Sink`：填写最终被消费的位置。
- `真实写边界`：填写写入目标对象的函数、语句、消息发送点或封装出口。
- `触发动作`：填写导致写入发生的用户动作、脚本动作或事件。
- `上游响应依赖`：填写写入前必须消费的响应字段或响应包编号；无则填 `无`。
- `Cookie 依赖`：只填写参与结果形成的 cookie 名称与来源。
- `状态载体依赖`：只填写具体状态载体、产生位置、读取位置。
- `正常态分支`：填写正常态命中的分支条件与证据位置。
- `风控态分支`：填写风控态命中的分支条件与证据位置；无则填 `无`。
- `证据定位`：按 `证据类型 / 定位符 / 位置` 填写，参考格式 `hook / createSign / file.js:218`；缺一项视为未填写。
- `未闭环项`：无则填 `无`。

# 恢复记录

用途：记录遮蔽层类型、恢复级别、语义边界、桥接契约和未恢复缺口。

填写规则：
- 只记录恢复结果，不写解释段落。
- 未闭环部分必须标注为缺口。
- 必须写明为什么恢复可以停在当前级别。

## 填写模板

- `样本编号`：
- `证据编号`：
- `遮蔽层类型`：填写 AST、控制流、`worker`、`WASM`、`JSVMP`、协议封装、`webpack/runtime` 等具体类型。
- `恢复级别`：只填 `A级 / B级 / C级` 之一。
- `停止理由`：填写为什么停在当前级别即可支撑下游。
- `入口锚点`：按 `入口 / 输入 / 输出 / 证据编号` 填写。
- `语义边界`：按 `边界标识 / 入口 / 出口 / 证据编号` 填写。
- `桥接契约`：填写层间输入、输出、状态传递、调度接口。
- `状态载体`：填写当前层依赖的寄存器、栈、上下文、闭包池、表、内存区等。
- `关键数据结构`：填写恢复出的关键对象、缓冲区、表结构、载荷结构。
- `关键函数卡片`：按 `函数 / 角色 / 输入 / 输出 / 证据编号` 填写；无则填 `无`。
- `协议语义`：填写字段映射、编码、包结构、消息语义；无则填 `无`。
- `已确认映射`：按 `源对象 -> 目标语义 / 证据编号` 逐条填写。
- `未恢复缺口`：只写仍缺失的边界、状态或语义。
- `下一恢复点`：只写下一个恢复切入点。
